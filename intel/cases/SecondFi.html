一、事件概述

2026年6月23日，EMURGO旗下Cardano钱包SecondFi（原名Yoroi）披露其Ed25519签名实现存在致命缺陷。钱包的签名代码在计算签名nonce时遗漏了唯一的秘密输入，使每个签名都退化为一个简单的线性方程，攻击者可直接从公开的链上交易数据恢复私钥。

两名独立攻击者分别清空了374个钱包，共窃取约1600万ADA（~$2.4M）。EMURGO随后紧急抢救了另外1.29亿ADA（~$19M）。

三、技术分析

3.1 Ed25519签名规范（正确实现）

Ed25519签名方案中，签名者持有：

  • k_L：签名标量（私钥）
  • k_R：秘密nonce前缀

对于消息M，正确的签名nonce计算：


r = SHA-512(k_R ∥ M) mod L

由于k_R是秘密的，即使M在广播后公开，r对观察者仍不可知。

最终签名(R, s)：


R = r·B  (B为Ed25519基点)
s ≡ r + H·k_L (mod L)
H = SHA-512(R ∥ A ∥ M) mod L

安全性核心：若r不可预测，签名方程s ≡ r + H·k_L有两个未知数(k_L和r)，无法求解。

3.2 SecondFi的致命缺陷

SecondFi的实现将签名nonce计算为：


r = SHA-512(M) mod L    ← 错误！去掉了k_R

正确应为：


r = SHA-512(k_R ∥ M) mod L    ← 正确

仅遗漏了一个哈希输入（k_R），后果是灾难性的：

  • M是公开的交易消息 → r变得可计算
  • r已知 → 签名方程变为单未知数线性方程
  • k_L可直接求解：k_L ≡ (s − r)·H⁻¹ (mod L)

这不是在破解密码学，是在做基础模运算。

3.3 攻击流程（6步恢复私钥）

整个攻击可完全离线完成：

  1. 识别目标：扫描使用v10.0.3-v10.0.6签署交易的地址
  2. 提取签名：从链上获取公开签名组件(R, s)，重构消息M
  3. 计算nonce：r = SHA-512(M) mod L
  4. 计算挑战：H = SHA-512(R ∥ A ∥ M) mod L
  5. 求解私钥：k_L ≡ (s − r)·H⁻¹ (mod L)
  6. 签署转账：用恢复的k_L签署交易，清空钱包

关键洞察：这不是在逆向哈希或求解离散对数。有缺陷的实现直接暴露了r，使密钥恢复简化为一次除法运算。

五、归因分析

两名攻击者独立行动（非协同），但都具备：

  • 对Ed25519签名数学的深入理解
  • 大规模链上数据扫描能力
  • 快速识别受影响版本的能力

攻击不遵循典型链上攻击序列（无前端交互、无钓鱼），完全是离线密码分析+链上转账。

六、独特分析角度

6.1 与Nonce Reuse攻击的对比

Nonce Reuse（如PSBT事件）SecondFi
原因两次签名用了相同nonce每次nonce都可从公开数据计算
恢复方式联立两个方程求解单个签名即可恢复

SecondFi比传统nonce reuse更严重：每个签名都是一个完整的密钥泄露。

6.2 "一行代码毁了一个百万美元钱包"

根因对比：

  • JaredFromSubway蜜罐：MEV bot未验证授权消耗 → $15M
  • Aztec Connect：ZK验证器numTxs参数绑定缺陷 → $2.1M
  • SecondFi：SHA-512输入少了k_R → $2.4M

三者共同点：密码学信任模型因实现层面的疏忽而瓦解。

  • 钱包签名实现审计是AI Agent可自动化的任务

七、经验教训

  1. 永远不要自己实现签名逻辑 — 使用经过审计的标准库
  2. 对规范的任何偏离都可能是致命的 — 少一个哈希输入 = 全部私钥泄露
  3. 生产级密码学代码必须独立审计 — 特别是密钥派生和签名操作
  4. 修复后必须生成全新密钥 — 导入助记词到修复版钱包不能保护已暴露地址
