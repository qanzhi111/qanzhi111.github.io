StakeDAO vsdCRV 无限铸币攻击事件链上调查报告

报告日期: 2026年5月28日

事件类型: 私钥泄露导致无限铸币攻击

涉及平台: Arbitrum

损失金额: ~$91,000 (43.78 ETH)

执行摘要

2026年5月27日，StakeDAO 基于 Arbitrum 的 vsdCRV 合约遭受攻击。攻击者利用泄露的部署者私钥，通过操纵 LayerZero v2 OFT peer 配置，在 Arbitrum 上铸造了约 5.446万亿枚 vsdCRV，并成功提取约 $91,000（43.78 ETH）。本次攻击的根本原因是 操作安全失败，而非智能合约代码漏洞。

技术分析

vsdCRV 代币机制

vsdCRV (Vote Boosted sdCRV) 是 StakeDAO 的流动性质押衍生品:

  • 与 Curve Finance 的 CRV 治理代币挂钩
  • 通过 StakeDAO 的 "Boosted Vote Strategy" 增强投票权
  • 使用 LayerZero v2 OFT 标准实现跨链互通

攻击机制详解

1. LayerZero OFT 工作原理

LayerZero OFT (Omnichain Fungible Token) 使用跨链铸造/销毁机制:

  • 代币在一个链上销毁，在另一个链上铸造
  • 依赖 peer 配置 验证跨链消息的合法性
  • peer 是每个链上注册的"信任地址"

2. 攻击向量


正常流程:
┌──────────────┐     跨链消息      ┌──────────────┐
│ Ethereum     │ ──────────────► │ Arbitrum     │
│ vsdCRVOFTAdapter │  (peer验证)   │ vsdCRV代币   │
│ (合法合约)    │                 │ (铸造)        │
└──────────────┘                 └──────────────┘

攻击流程:
┌──────────────┐     跨链消息      ┌──────────────┐
│ 恶意合约     │ ──────────────► │ Arbitrum     │
│ (攻击者控制)  │  (peer被篡改)   │ vsdCRV代币   │
└──────────────┘                 └──────────────┘
        ▲                              │
        │                              │
        └────── setPeer() 篡改 ────────┘
              (使用泄露私钥)

3. 关键漏洞点

漏洞类型描述严重程度
单点故障peer 配置由单一私钥控制，无多签保护高
无延迟机制配置变更后立即生效，无 timelock高
无额度限制铸造功能缺乏最大供应量检查高
跨链信任滥用伪造消息被 OFT 合约误认为合法高

漏洞根因分析

不是智能合约漏洞，而是操作安全失败

Sodot 联合创始人 Shalev Keren 指出:

> "There is no smart contract bug here and no flaw in LayerZero. There is one private key, controlling one privileged configuration function, with no multisig and no delay between the configuration change going through and the mint clearing onchain."

调查报告总结

关键发现

  1. 攻击性质: 私钥泄露 + LayerZero OFT peer 操纵
  2. 损失规模: 铸造 5.446T vsdCRV，实际获利 ~$91K
  3. 根本原因: 单一私钥控制关键配置，无多签/延迟保护
  4. 漏洞利用: 跨链消息伪造，触发无背书代币铸造

风险指标

指标评级
财务损失中等 ($91K)
信任损害高
系统性风险中等
可追溯性高 (完整链上记录)

预防建议

对于 DeFi 协议:

  • 关键配置变更必须使用多签钱包
  • 实施 timelock 延迟机制
  • 定期轮换部署者密钥
  • 监控异常配置变更

对于用户:

  • 评估协议的密钥管理实践
  • 优先选择有完善治理的协议
  • 关注协议安全公告
  • 避免在安全事件期间交互受影响的代币
