SwissBorg $41.5M SOL Staking Hack — 链上调查报告

> 调查日期：2026-07-15

> 事件时间：2026-07-15（今日发生）

> 损失金额：~$41.5M（SOL）

> 攻击类型：Partner API Compromise（第三方API供应链攻击）

> 链：Solana

> ZachXBT覆盖状态：✅ 已在Telegram发出警报，但尚无深度调查Thread

事件概述

2026年7月15日，瑞士加密钱包/交易所SwissBorg遭受重大黑客攻击。攻击者通过入侵SwissBorg的SOL Earn质押协议的合作伙伴API，盗取了约$41.5M的Solana代币。

知名链上侦探ZachXBT率先在Telegram频道发出警报，估计总损失约$41.5M。随后SwissBorg官方确认了事件。

攻击向量分析

Partner API Compromise — "你的合作伙伴就是你的攻击面"

本次攻击的核心特征是第三方API供应链攻击：

  1. SwissBorg的SOL Earn质押服务依赖合作伙伴API进行质押操作
  2. 攻击者入侵了该合作伙伴API
  3. 通过被入侵的API，攻击者获得了转移SOL代币的能力
  4. 大量SOL被从质押协议中抽走

关键洞察：SwissBorg自身的安全可能是完好的，但其信任的第三方合作伙伴成为了突破口。这与2026年的整体攻击趋势高度一致——攻击者越来越多地转向"边缘"而非"核心"：

  • Kelp DAO $292M — LayerZero桥接验证节点被入侵
  • Drift Protocol $285M — 社会工程攻击获取multisig签名密钥
  • Humanity Protocol $36M — 员工笔记本被钓鱼入侵
  • SwissBorg $41.5M — 合作伙伴API被入侵

  • CEO Cyrus Fazel计划当日下午进行直播，解释事件详情及后续步骤

  • 但全额赔偿取决于是否能追回被盗资金
  • 其他代币的质押协议未受影响

  • 以其"Smart Exchange"技术和多链支持闻名

  • Arkham Intelligence数据显示，事发前SwissBorg持有约$72.6M的SOL
  • 本次事件意味着失去了其约57%的SOL持仓

ChainSentinel关联分析

本次事件再次验证了ChainSentinel"API/第三方安全审计"赛道的市场需求：

  1. DeFi协议的第三方依赖风险：大多数协议依赖多个外部API和合作伙伴，但很少对这些依赖进行持续安全审计
  2. API供应链攻击的可检测性：通过链上监控，可以检测异常的API调用模式和大规模资金转移
  3. 实时预警价值：如果SwissBorg有链上实时监控系统，在资金异常转移的早期就能触发警报
