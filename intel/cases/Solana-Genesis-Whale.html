一、事件概述

一个与Solana 2020年创世区块分发相关联的远古鲸鱼钱包，在沉睡超过5年后突然被清空。约180,900枚SOL（价值~$14.2M）被盗窃，攻击者在发现异常解质押活动后迅速介入，在数小时内完成全部资金清洗。

独特角度：这不是合约漏洞、不是桥接攻击——这是OPSEC失败的典型案例。持有SOL超过5年从未出问题的创世级鲸鱼，在最基础的密钥安全上败北。

三、攻击向量分析

3.1 已知信息

  • 攻击方法：未公开确认
  • 可疑迹象：异常解质押活动 → 攻击者可能在监控该钱包
  • 可能向量：
  1. 私钥泄露/被窃取
  2. 社会工程攻击
  3. 恶意钓鱼合约交互
  4. 硬件钱包供应链攻击
  5. 钱包软件漏洞（影响创世分发钱包的老旧软件）

3.2 关键线索：解质押触发

Specter Investigation首先发现"不寻常的解质押活动"，随后追踪到资金被盗。这暗示：

  • 攻击者可能需要先触发解质押才能获取SOL
  • 或者攻击者监控到了所有者发起的解质押操作，抢先介入
  • Solana的质押解除通常需要数个epoch（~2-3天），但此次似乎加速完成

3.3 为何5年未被触碰？

创世分发钱包的特征：

  • 大量资金、长期不活跃
  • 所有者可能使用老旧的钱包软件
  • 可能从未更新安全措施
  • 5年的"安全"可能给了虚假的安全感

5.2 跨链桥作为洗钱工具

攻击者的清洗路径：Solana → Mayan Finance → Ethereum

Mayan Finance成为攻击后的首选桥接工具，原因：

  • 无需KYC
  • 快速跨链
  • 在SOL-ETH交换中流动性充足

5.3 OPSEC教训

"审计过的代码在人的环节出错时依然失败。"

即使持有超过5年没有任何问题，单个密钥泄露就能让所有资产归零。这对整个行业都是一个警示：

  1. 硬件钱包 ≠ 绝对安全 — 如果助记词在其他地方暴露
  2. 长期安全 ≠ 永久安全 — 5年没问题不代表第6年也安全
  3. 监控钱包活动 — 设置链上警报，第一时间发现异常
  4. 分散存储 — 不要把所有资产放在一个地址
