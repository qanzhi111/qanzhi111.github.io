技术分析

根本原因：伪随机数生成器（PRNG）不安全

加密钱包的种子词（助记词）本质上是一串随机数。BIP-39标准要求使用密码学安全的随机数生成器（CSPRNG）来生成种子。

问题所在： 部分钱包在种子生成流程中使用了不安全的随机性源，导致：

  • 实际可能的种子空间远小于理论值（2^256）
  • 攻击者可以通过逆向PRNG算法，在数天内穷举可能的种子
  • 一旦匹配到链上地址，即可推导出私钥并控制钱包

攻击模式


弱PRNG种子生成 → 可预测的种子空间 → 暴力枚举 → 匹配链上地址 → 推导私钥 → 转走资产

关键特征

  1. "无声的收割"模式：攻击者扫描弱种子地址，发现有钱进来就顺手提走
  2. 大部分被盗未公开：受害者通常以为是钓鱼或设备被黑
  3. 资金集中归集：部分资金流向呈现集中转入单一地址及疑似洗钱特征
  4. 持续性攻击：8年来持续存在，不是单次事件
  5. 跨链风险：同一弱种子词可能控制多条链上的资产

与Milk Sad研究的关系

Coinspect报告明确引用了Milk Sad研究作为类似模式的先例。Milk Sad发现弱随机性导致钱包种子空间被大幅缩减，使理论上不可能暴力破解的助记词变成可计算的目标。

为什么这是系统性风险

1. 不可修复性

  • 种子词一旦生成，其安全性就永远绑定于生成时的随机性
  • 更新钱包App不能修复已生成的弱种子
  • 将弱种子导入新钱包不能修复问题

2. 隐蔽性

  • 用户无法自行检测种子是否由弱PRNG生成
  • 被盗后通常误判为钓鱼/设备感染
  • 区块链地址设计上不暴露种子的生成方式

3. 跨链连锁

  • 一个弱种子可能控制Ethereum、Bitcoin、Solana等多条链的资产
  • 攻击可能不会同时出现在所有链上，增加检测难度

用户行动建议

立即行动

  1. 检查是否使用了已被点名的钱包应用
  2. 关注Coinspect后续公布的受影响钱包列表
  3. 如怀疑受影响，不要将种子导入其他钱包——而是用新安全种子创建全新钱包

长期防护

  1. 使用硬件钱包（Ledger/Trezor）—— 硬件钱包的种子生成在安全芯片中完成
  2. 选择Coinspect Wallet Security Ranking高分钱包
  3. 大额资产永远不放在软件钱包
