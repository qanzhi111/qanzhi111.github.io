CryptoBandits.A / Crypto Clipper 深度调查报告

调查日期： 2026-06-21

事件披露日期： 2026-06-17（Microsoft Security Blog）

活跃时间： 2026年2月至今

检测名称： Trojan:Win32/CryptoBandits.A

威胁类型： USB蠕虫 + 剪贴板劫持 + 加密货币窃取木马

影响平台： Windows（通过USB可移动设备传播）

受害币种： BTC、ETH、XMR（门罗币）

一、事件概述

2026年6月17日，微软安全研究团队（Microsoft Security Blog）披露了一种名为 Crypto Clipper 的新型加密货币窃取木马。该恶意软件自2026年2月起活跃，主要通过USB设备传播恶意.lnk快捷方式感染Windows用户。微软将其检测为 Trojan:Win32/CryptoBandits.A。

这是一种具备蠕虫传播能力的恶意软件，会自动隐藏U盘内原始文档并生成同名恶意快捷方式，同时创建计划任务实现持久化控制。

二、攻击链分析

2.1 初始感染 - USB蠕虫传播

  1. 传播载体： USB可移动设备
  2. 感染机制：
  • 自动隐藏U盘内原始文档/文件
  • 生成与原始文件同名的恶意.lnk快捷方式
  • 用户点击快捷方式时触发恶意载荷
  1. 伪装手法： 快捷方式图标与原始文件高度相似，用户难以辨别

2.2 持久化驻留

  • 创建Windows计划任务（Scheduled Task）实现开机自启
  • 利用EFI系统分区隐藏恶意文件，规避安全产品检测
  • 恶意文件存储在 %SystemRoot%\Installer 目录

2.3 C2通信

  • 内置Tor客户端
  • 通过本地SOCKS5代理（localhost:9050）连接.onion隐藏服务
  • 实现完全隐蔽的命令与控制通信
  • 传统防火墙和网络监控难以识别

2.4 核心恶意功能

功能描述
剪贴板劫持每500毫秒高频监控剪贴板，匹配加密货币钱包地址格式后替换为攻击者地址
助记词/私钥窃取扫描本地文件系统中的钱包备份文件
地址替换替换用户复制的BTC/ETH/XMR转账地址
屏幕截图定期截取屏幕并上传至C2
远程代码执行接收并执行远程指令

三、技术特征

3.1 剪贴板监控机制

恶意软件持续监控Windows剪贴板内容（每500毫秒一次），使用正则匹配以下钱包地址格式：

  • Bitcoin地址： 以1、3或bc1开头
  • Ethereum地址： 0x前缀 + 40位十六进制字符
  • Monero地址： 4开头 + 94位字符

匹配成功后，将用户剪贴板中的地址替换为攻击者控制的地址。用户在转账时如果从剪贴板粘贴地址，资金将被转入攻击者钱包。

3.2 规避检测技术

  1. EFI分区隐藏： 将恶意文件存储在EFI系统分区，安全产品通常不扫描此区域
  2. Tor加密通信： 所有C2通信通过Tor网络，无直接可追踪IP
  3. 延迟执行： 避免在沙箱环境中暴露恶意行为
  4. 合法进程注入： 将恶意DLL注入到合法系统进程中

3.3 IOC指标

  • 检测名称： Trojan:Win32/CryptoBandits.A
  • Tor代理端口： localhost:9050
  • 恶意文件路径：
  • %SystemRoot%\Installer\ 目录下的可疑文件
  • EFI系统分区中的隐藏文件
  • 网络特征： 本地SOCKS5代理连接.onion域名
  • 行为特征： 高频剪贴板访问、异常计划任务

四、威胁评估

4.1 攻击面分析

维度评估
传播方式USB蠕虫，物理接触传播，绕过网络隔离
目标精准度专门针对加密货币用户，非通用木马
隐蔽性极高（Tor通信+EFI隐藏+进程注入）
危害程度高（直接资金损失，无中间人可追溯）
检测难度中高（传统签名检测有效，行为检测困难）

4.2 独特分析角度

  1. 物理攻击面回归： 在网络隔离和硬件钱包普及的背景下，USB攻击面重新成为高风险向量。攻击者选择物理传播意味着目标可能是高价值用户（如交易所员工、OTC交易员）。
  1. "剪贴板劫持"的进化： 传统剪贴板劫持木马（clipper malware）在加密货币领域由来已久，但CryptoBandits.A结合了USB蠕虫传播+Tor隐蔽通信+EFI持久化，代表了此类攻击的工程化升级。
  1. 供应链隐喻： 当用户将感染的USB设备插入多台电脑时，蠕虫特性使得攻击可沿物理链条扩散，形成类似软件供应链攻击的效果。
  1. 与ChainSentinel的关联： 此类攻击正是ChainSentinel产品可以覆盖的场景——"AI Agent链上独立审计"可延伸至端点安全领域，检测钱包地址替换行为。

五、防御建议

5.1 用户层面

  1. 禁用USB自动运行： Windows组策略禁用可移动设备AutoRun
  2. 验证剪贴板地址： 转账前对比剪贴板内容与实际钱包地址的前6位和后6位
  3. 使用地址簿： 常用收款地址使用地址簿功能，避免复制粘贴
  4. 监控Tor流量： 检查localhost:9050端口是否有异常连接
  5. 硬件钱包用户： 硬件钱包的屏幕显示地址不受此影响，但仍需警惕恶意软件窃取助记词

5.2 企业层面

  1. 限制脚本解释器执行权限（PowerShell、WScript等）
  2. 部署EDR监控异常剪贴板访问行为
  3. 对可移动设备实施白名单策略
  4. 定期检查EFI分区异常文件
  5. 将CryptoBandits.A相关IOC纳入威胁情报平台
