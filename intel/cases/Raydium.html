Executive Summary

2026年6月10日，攻击者利用Raydium已废弃5年的AMM V3合约中缺失的LP mint地址验证逻辑，从5个遗留流动性池中抽取$1.34M资产。ChainBounty于6月15日发布的完整法证分析揭示了专业化的资金清洗链条——结构化拆分(peel chain) → 跨链桥接 → Tornado Cash混合——以及一个关键归因锚点：攻击者钱包的初始资金来自KuCoin KYC账户。

Attack Vector Analysis

漏洞机制

Raydium AMM V3程序在withdraw函数中存在关键验证缺陷：接受LP Token作为提款凭证时，仅验证Token供应量，不验证mint地址是否为该池的合法LP Token。

攻击步骤

  1. 攻击者创建全新SPL Token mint（伪造LP Token，与任何Raydium池无关）
  2. 铸造1个单位的伪造Token
  3. 调用legacy withdraw函数，传入伪造mint地址
  4. 旧合约接受伪造Token，将攻击者视为100% LP持有者，释放全部池资产
  5. 对5个废弃池重复此操作

Phase 3 — 汇聚于桥接准备Hub

所有9个中间人集群将USDC汇聚至单一地址2snHHreX...。此"汇聚"模式表明：拆分并非永久性分散，而是为了创造法证噪声的层化操作。层化完成后，资金重新汇聚准备跨链退出。从攻击到汇聚的总时间以小时计，非以天计。

Phase 4 — 跨链桥接：Solana → Ethereum

从桥接准备Hub，全部余额从Solana桥接至Ethereum。具体桥接协议尚未通过链上直接验证确认（基于PeckShield追踪报告，属可信但未独立验证线索）。多方独立安全研究员确认：资金在离开Solana后不久即到达Ethereum。

Attribution Anchor：KuCoin

本案最关键的归因线索：攻击者钱包的初始资金来自KuCoin。

在攻击发生前，攻击者从KuCoin账户接收运营资金（可能用于gas和测试交易）。KuCoin作为强制KYC注册的中心化交易所，持有该账户的身份记录。正式法律请求（法院命令、MLAT或相关司法管辖区的自愿合作请求）可向KuCoin获取攻击者的真实身份。

这是整个案件中唯一可行的归因锚点。

攻击者执行了专业化的清洗序列（结构化→跨链→混合），但犯了一个老练攻击者通常避免的错误：通过KYC交易所为运营钱包提供资金。

系统性教训

1. Deprecated ≠ Disabled

从UI移除的合约不等于已停用的合约。在无需许可的区块链上，如果程序已部署且可调用，任何人都可以调用——无论UI是否仍暴露它。

2. 遗留代码中的真实资产

更深层的失败不仅是旧AMM V3存在于链上，而是真实资产仍留在其中。当Raydium在2021年迁移到AMM V4和CLMM时，应从弃用池进行完整的资产迁移。5年的休眠加上真实流动性，精确创造了攻击者利用的条件。

3. 清洗模式可预测但有效

攻击者遵循安全研究员广泛记录的模式：结构化→跨链桥→混合器。可预测性是双刃剑——使追踪对调查人员更容易，但也证明混合器和桥接仍是DeFi攻击者的首选清洗基础设施。

4. Raydium的应对模式

Raydium承诺从项目国库全额补偿受影响LP。这与2022年12月$4.4M私钥泄露事件的处理模式一致（通过治理批准的补偿使用回购费和团队 vesting token）。

回收前景

坦率判断：$1.34M不太可能全额回收。

  • 810 ETH进入Tornado Cash——实际不可追踪
  • FixedFloat提供有限的追索可能
  • Ethereum端桥接目的地地址在发布时未获独立链上确认

调查人员实际拥有的：

  • Solana端完整资金流逐跳重建
  • KuCoin作为KYC关联资金来源——最强归因线索
  • 攻击者主Solana地址完整映射
  • 结构化模式记录——构成蓄意层化的链上证据
