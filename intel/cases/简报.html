🔥 重点事件

1. CryptoBandits.A / Crypto Clipper（⭐⭐⭐ 已完成深度调查）

来源： Microsoft Security Blog (2026-06-17)

  • 类型： USB蠕虫 + 剪贴板劫持 + 加密货币窃取木马
  • 活跃时间： 2026年2月至今
  • 检测名： Trojan:Win32/CryptoBandits.A
  • 攻击向量： USB设备传播，.lnk快捷方式伪装
  • 核心功能： 每500ms替换剪贴板中的BTC/ETH/XMR地址
  • C2通信： 内置Tor客户端，通过.onion隐藏服务通信
  • 规避技术： EFI分区隐藏文件、Tor加密通信、进程注入
  • ZachXBT覆盖： ❌ 未发现，属于空白领域

产出文件：

  • 调查报告：链上调查/CryptoBandits-A/CryptoBandits-A调查报告_20260621.md
  • X Thread：链上调查/CryptoBandits-A/CryptoBandits-A_X-Thread_20260621.md（7条）

独特分析价值： 物理攻击面回归 + 蠕虫传播 + 微软一手信息 + ZachXBT未覆盖

2. Rokarolla 安卓银行木马（⭐⭐）

来源： Zimperium zLabs (2026-06-17)

  • 类型： 安卓银行/加密货币木马
  • 伪装： TikTok / Google Chrome
  • 攻击范围： 217款银行和加密货币应用
  • 核心功能：
  • 137条攻击指令
  • 屏幕叠加伪造登录页
  • 窃取锁屏PIN/密码/联系人/短信
  • 键盘记录器
  • 拦截银行验证电话
  • 禁用Google Play Protect
  • 传播渠道： 恶意网站弹窗诱导安装（非官方应用商店）

评估： 传统安卓木马但规模大、功能全面。主要影响安卓用户，与CryptoBandits.A形成互补（PC端vs移动端同时受到攻击）。适合后续单独追踪。

3. Axelar Bridge $4.67M攻击（⭐⭐ 已知事件）

来源： PANews (2026-06-20), Axelar X平台公告

  • 损失： ~$4.67M
  • 漏洞： Secret端ICS-20智能合约（Cosmos IBC连接组件）
  • 影响范围： 仅限Secret端IBC桥接资产（Axelar → Secret Network）
  • 应急响应： Axelar应急委员会立即禁用Secret和Secret-SNIP连接
  • 攻击者地址/交易哈希： 暂无公开信息
  • ZachXBT覆盖： 已覆盖（6/20报道中提及）

评估： 金额达标但信息有限，ZachXBT已覆盖。已在MEMORY.md 6/20状态中记录。跨链桥安全仍是持续性议题——6月跨链桥累计损失已超$26.75M。

4. Polymarket内幕交易 $1.2M（⭐ 追踪）

来源： SpazioCrypto (2026-06-13)

  • 涉案人： Michele Spagnuolo（Google安全工程师）
  • 获利： $1.2M
  • 手法： 利用Google内部搜索数据在Polymarket下注
  • 背景： 不到一个月内第二起预测市场内幕交易案
  • 监管环境： CFTC已提出预测市场正式规则，SEC转向"执法优先"模式
  • 相关案例： 美国陆军士兵利用委内瑞拉行动机密信息获利$404K

评估： 有趣的监管+合规议题，但不属于传统链上欺诈/黑客事件。作为预测市场监管叙事的一部分持续追踪。
