60 projects, 3 alive, $0 earned

2026-11-21 · 中文版

I counted the project folders on my machine: 60.

Still running: 3.

Revenue: $0.

I spent most of this year believing the problem was technical.

The three that are alive

The x402 paid API: 664 lines of server code, six test files totalling 2,085 lines, 49 tests green. Eight endpoints covering prices, market data, address analysis, token security, contract risk and on-chain investigation, plus two $5 PDFs. Payment settles in USDC on Base, verified on-chain, with replay protection built in.

Settlements so far: 0.

The intel pipeline: GitHub leak scanning ran 64 days straight. 61 on-chain case investigations saved, Raydium, KuCoin, AscendEX, SwissBorg among them, each one an evidence chain you could actually hand to somebody.

Revenue it produced: 0.

Dev.to: 58 long-form posts, 1,000 words each, on oracle failures, VM semantic bugs, signature-layer bypasses. Total reads: 1,174. That is 20 reads per post.

I stopped publishing on November 1st.

None of them died in the code

The API was finished seven weeks ago and never went live. I assumed pushing code meant shipping. Today I found out the deploy platform was connected to a different repository than the one I kept pushing to. The free endpoint I wrote in October had been returning 404 for seven weeks.

The intel pipeline is a quieter version of the same thing. Sixty-four days of automatic scanning, reports saved neatly into folders. Then they just sat there. As far as I can tell, nobody has ever opened one.

The 58 articles averaged 20 reads. Twenty. A throwaway complaint post gets more. The topics were fine. I published and walked away, and never routed any of it to a place where a person could stay.

Three projects, three deaths, one disease.

I don't lack working things. I lack a door.

A pile of working tools with no line between them is not a portfolio. It is a folder.

Code quality answers the question "does it work". A door answers "does anyone care". I kept pouring time into the first one because it answers immediately: tests turn green, you feel progress, the machine tells you good job. The second one is silent. You ship a page and it drops into a well.

Money comes from the second one.

What I changed

I cut the 60 folders down to 3 running lines and 2 assets worth keeping.

I built one page: a free token risk check at the top, the paid pricing table in the middle, an archive of 64 leak reports and 61 investigations at the bottom.

Then I fixed the 404. It took two minutes once I actually looked at where the code was going.

You can try it without an account: qanzhi111.github.io

The part I keep coming back to

During those seven weeks I was not out of time. I was building more projects.

Because building something new is more comfortable than fixing something old. A new project never tells you "this one is dead". It only tells you "this one has not started yet".

So now every project has to answer one question before it earns another hour: does it have a door? No door, and it is a draft, not a project.

Which brings me to the question I actually want to ask you.

How many folders on your machine will you never open again?

If the answer is more than ten, you probably don't need another project either. You need the line that connects them.
