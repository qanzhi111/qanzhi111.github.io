How an agent pays

      
Call any route. The server answers 402 with an x402 payment request. The agent signs a USDC transfer on Base, retries with the receipt, and gets the data.

      
Payment receipts are verified on-chain and each one is good for one call. Two routes are offline on purpose: they used to charge and return an empty report, so they now stop before payment.
